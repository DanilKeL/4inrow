# FOUR³ в Telegram

Адрес Mini App: **https://4inrow.ru/?telegram=1**.

Бот: [@forinrow_bot](https://t.me/forinrow_bot).
После настройки основной Mini App ссылка запуска:
**https://t.me/forinrow_bot?startapp**.

Это существующая FOUR³: объёмное поле, игра против AI, локальный режим,
уровни и онлайн-партии. Telegram SDK загружается только при открытии из
Telegram или с параметром `telegram`, обычный офлайн-запуск остаётся доступен.

В Telegram при запуске запрашивается полноэкранный режим (`requestFullscreen`,
Bot API 8.0+). Если клиент его не поддерживает, окно остаётся развёрнутым.
При выходе пользователя из полноэкранного режима повторного запроса нет.
Учитываются высота и безопасные отступы, включая изменения при переходе
в полноэкранный режим,
работают нативная кнопка «Назад», пункт настроек и виброотклик.
При сворачивании локальная партия приостанавливается. Онлайн-таймер продолжает
работать по серверным правилам. Закрытие незавершённой партии требует подтверждения.
Кнопка «Войти через Telegram» в личном кабинете передаёт сырые `initData`
серверу, который проверяет HMAC-подпись и время выдачи. Первый вход создаёт
аккаунт без обязательных email и пароля; повторный вход находит тот же аккаунт
по Telegram ID. Для сохранения существующего Elo и прогресса сначала войдите
обычным способом, затем выберите «Привязать Telegram» в разделе «Безопасность».
Непроверенным `initDataUnsafe` и совпадениям никнеймов сервер не доверяет.

## Подключение через BotFather

1. Откройте проверенного [@BotFather](https://t.me/BotFather).
2. Создайте бота командой `/newbot` или выберите своего через `/mybots`.
3. В **Bot Settings → Menu Button** задайте URL `https://4inrow.ru/?telegram=1`
   и текст `Играть в FOUR³` (или используйте `/setmenubutton`).
4. В **Bot Settings → Configure Mini App → Enable Mini App** подключите тот же URL
   для основной Mini App и добавьте её название/обложку.
5. Откройте чат со своим ботом и нажмите кнопку меню. После подключения основной
   Mini App её можно открыть ссылкой `https://t.me/forinrow_bot?startapp`.

Для настройки кнопки через API предусмотрен `node scripts/telegram-setup.mjs`.
Токен читается из локального файла `секреты/telegram-bot-token.txt` (исключён
из Git) или переменной окружения `TELEGRAM_BOT_TOKEN`. Другой путь к файлу можно
задать через `TELEGRAM_BOT_TOKEN_FILE`. Ожидаемый бот — `forinrow_bot`;
для другого бота задайте `TELEGRAM_BOT_USERNAME`. Адрес читается из
`TELEGRAM_APP_URL` (необязательно). Не сохраняйте токен в исходниках и не
передавайте его аргументом командной строки. Скрипт не отправляет сообщения.

## Вход на сайте

Официальный Telegram Login SDK использует OIDC. В BotFather → Login Widget
добавьте `https://4inrow.ru` в Allowed URLs. В защищённом серверном файле
`/etc/four-game/telegram.env` укажите `TELEGRAM_LOGIN_CLIENT_ID` из BotFather
и существующий `TELEGRAM_BOT_TOKEN` для Mini App. Client Secret этому варианту
входа не нужен. Systemd читает файл через EnvironmentFile; токен не попадает
в браузер, исходники или GitHub. При необходимости сохраняется существующий
`TELEGRAM_API_ADDRESS`: он выбирает доступный маршрут к Telegram с проверкой
сертификата официального домена, без подмены TLS-имени.

На сервере проверяются подпись JWT по официальному JWKS, issuer, audience,
срок действия и одноразовый nonce. Попытка входа связана с HttpOnly-cookie
конкретного браузера и аккаунтом для привязки; повторное использование отклоняется.
Запрашивается только `profile`: телефон и разрешение на рассылку не нужны.
Заблокированные аккаунты не могут войти через Telegram. Никнейм меняется в
Telegram независимо от имени аккаунта игры; Elo, статистика и уровни сохраняются.
Пользователь без Telegram username получает уникальное имя `tg_<ID>`.
При совпадении с существующим никнеймом создаётся отдельное уникальное имя.
В разделе безопасности Telegram-аккаунт может дополнительно создать пароль.

## Проверка авторизации

`npx vitest run server/telegramAuth.test.ts server/app.test.ts` — подписи,
одноразовые сеансы, ограничения времени, привязка, отсутствие захвата аккаунта,
сохранение на диске и обычные онлайн-сценарии.
`npx playwright test e2e/telegram-auth.spec.ts --project=chromium` — UI сайта
и Mini App, повторный вход, создание пароля, привязка с сохранением прогресса
и обработка неподтверждённого токена. SDK имитируется, токен подписывается
тестовым RSA-ключом и проверяется изолированным настоящим API.

## Проверка Mini App

`npm run build` и `npm test` — сборка и модульные тесты.
`npx playwright test e2e/telegram.spec.ts --project=chromium` — мобильное окно
с имитацией Telegram SDK: полноэкранный запуск, ход касанием, safe area, нативная навигация,
виброотклик и пауза при сворачивании.
Проверка с настоящим Telegram требует подключённого бота и телефона.

API: [официальная документация Telegram Mini Apps](https://core.telegram.org/bots/webapps).
