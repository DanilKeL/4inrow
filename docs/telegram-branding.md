# Оформление @forinrow_bot

Название: **FOUR³ · Четыре в ряд**.
Короткое описание: «Четыре в ряд в трёх измерениях. AI, друзья, уровни и задача дня.
Думай на уровень выше — прямо в Telegram.»

Название и оба описания настроены для русского языка, по умолчанию и на английском.
Аватар — существующий логотип F³ в фирменном синем цвете.
Файлы находятся в `public/telegram`: `four-avatar.jpg`, `four-cover.jpg` (640 × 360)
и `four-cover-master.png`.

Команды `/start` и `/play` возвращают заставку и кнопку запуска Mini App.
`/help` объясняет правила и тоже предлагает открыть игру.
Ответы отправляются только на команды пользователя в личном чате.

Приветствие обслуживает отдельная служба `four-telegram-bot` на существующем сервере.
Игровой сервер продолжает работать отдельно. Состояние обработки команд
хранится в `/srv/four-game-data/telegram-state.json`, а токен — в
`/etc/four-game/telegram.env` с правами 0600, вне публикуемых исходников.

Сервер использует `TELEGRAM_API_ADDRESS=149.154.167.220`: его сеть не достигает
второго адреса Telegram из DNS. TLS продолжает проверять официальный
`api.telegram.org`; общесистемные DNS и настройки сертификатов не меняются.

## Заставка до команды /start

Картинка над полем «Что умеет этот бот?» настраивается отдельно через BotFather:
`/mybots` → `@forinrow_bot` → **Edit Bot → Edit Description Picture**.
Загрузите `public/telegram/four-cover.jpg` как фотографию.
Это настройка профиля владельца; Bot API для неё не предоставляет метода.
После `/start` тот же дизайн автоматически приходит в приветственной карточке.

Источник: [Telegram: About text, description and profile media](https://core.telegram.org/bots/features#about-text-description-and-profile-media).

## Проверка и обслуживание

`node --test scripts/telegram-content.test.mjs` проверяет карточку, правила,
кнопку Mini App и отсутствие ответов в группах или на обычный текст.
Проверка службы: `systemctl status four-telegram-bot`.
Логи: `journalctl -u four-telegram-bot -n 30 --no-pager`.
Для замены токена измените секретный env-файл и перезапустите эту службу.

Заставка создана встроенным ImageGen по материалам проекта. Финальный промпт
и промпт уточнения сохранены в `public/telegram/cover-prompts.txt`.
